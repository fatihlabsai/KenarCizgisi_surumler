# Kenar Çizgisi — Sürümler

Bu depo yalnızca **Kenar Çizgisi**'nin yayınlanmış Windows sürümlerini barındırır. Oyunun kodu burada değildir.

- Oyun yeni sürümleri bu depodan **otomatik** olarak indirir. İnince ana menünün sağ altında bildirim çıkar.
- Elle kurmak için **Releases** bölümündeki en son `KenarCizgisi-Setup-x.y.z.exe` dosyasını indir.
- Güncellemeler kayıtlarını silmez (`%APPDATA%\KenarCizgisi\saves`).
